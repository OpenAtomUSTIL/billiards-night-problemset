# T18 巡回敬杆（省选 / NOI−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T18【省选 / NOI−】巡回敬杆

**算法标签：状态压缩 DP（旅行商问题）**

### 题目背景

作为今晚的东道主兼买单人，小民要在打烊前到每张球桌敬一杆、打个招呼，然后回到前台。台球厅就这么大，他想走最短的路。

### 题目描述

台球厅里有 $n$ 个站点（1 号是前台），任意两个站点 $i, j$ 之间的距离为 $d_{i,j}$。小民从 1 号出发，**每个站点恰好经过一次**，最后回到 1 号。求最短巡回路线长度。

### 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行 $n$ 个整数，第 $i$ 行第 $j$ 个数为 $d_{i,j}$。保证 $d_{i,i} = 0$，$d_{i,j} = d_{j,i}$。

### 输出格式

一行一个整数，表示最短巡回长度。

### 样例

```text
输入：
4
0 1 2 3
1 0 1 2
2 1 0 1
3 2 1 0

输出：
6
```

**样例解释：** 走 $1 \to 2 \to 3 \to 4 \to 1$，长度为 $1 + 1 + 1 + 3 = 6$。

### 数据范围

- 对于 30% 的数据，$n \le 10$；
- 对于 100% 的数据，$2 \le n \le 16$，$0 \le d_{i,j} \le 10^6$。
