# T07 黑八的轨迹（NOI / NOI+ / CTSC）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T7【NOI / NOI+ / CTSC】黑八的轨迹

**算法标签：计算几何 / 数论（镜像展开 + 模运算 + 逆元）**

### 题目背景

决胜局只剩黑八。小民深吸一口气，把运气值拉满 300%，击出了注定载入台球厅史册的一杆。小欣死死盯着球的轨迹——他要知道这颗球到底会撞向哪里。

### 题目描述

把球桌看作平面直角坐标系中的矩形 $[0, W] \times [0, H]$，四条边（库边）均为完美弹性反射面（入射角等于反射角）。

母球从点 $(x_0, y_0)$ 出发，沿方向向量 $(v_x, v_y)$ 匀速运动（保证 $v_x^2 + v_y^2 > 0$）。

球在碰到库边时发生镜面反射；若同一时刻同时碰到两条相邻库边（即进袋口），轨迹将无法定义——题目**保证**这种情况永远不会发生，且球的出发位置不在任何袋口上。

小欣想知道：从出发开始，母球**第 $k$ 次**碰到库边的位置坐标 $(x^*, y^*)$。

可以证明 $x^*, y^*$ 均为有理数。请分别输出它们对 $10^9+7$ 取模的结果：若有理数为 $\frac{a}{b}$（$\gcd(a,b)=1$），则输出 $a \cdot b^{-1} \bmod (10^9+7)$，其中 $b^{-1}$ 为 $b$ 在模 $10^9+7$ 意义下的逆元。

### 输入格式

第一行四个整数 $W, H, x_0, y_0$。

第二行两个整数 $v_x, v_y$。

第三行一个整数 $k$。

### 输出格式

一行两个整数，分别表示 $x^*$ 和 $y^*$ 对 $10^9+7$ 取模的结果。

### 样例

```text
输入：
3 2 1 1
1 2
3

输出：
3 1
```

**样例解释：**

- 第 1 次碰库：$t = 0.5$，位置 $(1.5, 2)$（上库）；
- 第 2 次碰库：$t = 1.5$，位置 $(2.5, 0)$（下库）；
- 第 3 次碰库：$t = 2$，位置 $(3, 1)$（右库）。

故输出 `3 1`。

### 数据范围

- 对于 20% 的数据，$k \le 10^3$；
- 对于 50% 的数据，$k \le 10^6$；
- 对于 100% 的数据，$1 \le W, H \le 10^6$，$0 \le x_0 \le W$，$0 \le y_0 \le H$，$-10^6 \le v_x, v_y \le 10^6$，$1 \le k \le 10^{18}$。

**提示：** 将反射展开为镜像平面中的匀速直线运动：在展开平面中，「碰库」等价于横坐标到达 $W$ 的整数倍、或纵坐标到达 $H$ 的整数倍。于是问题转化为：两组等差时刻序列的归并中，找到第 $k$ 早的时刻——可以用数学方法（二分时刻 + 计数，或类欧几里得算法）在 $O(\log)$ 级别定位，最后将展开坐标对 $2W$、$2H$ 折返映射回原球桌。注意中间过程全部为有理数运算，用模意义下的分数（分子、分母分别取模）维护即可。
