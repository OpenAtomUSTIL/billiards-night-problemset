# T33 最后三堆球（省选 / NOI−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T33【省选 / NOI−】最后三堆球

**算法标签：博弈论（Nim 游戏 / SG 函数）**

### 题目背景

真正的决胜局：球桌上摆着 $n$ 堆彩球，小民和小欣轮流操作，每次必须从某一堆中取走**至少一颗**球（可以取完整堆），取走最后一颗球的人获胜。小民先手。小欣焚香的手微微颤抖——她要先算好这局到底是不是必败。

### 题目描述

给定 $n$ 堆球，第 $i$ 堆有 $a_i$ 颗。小民先手，两人轮流取球，每次任取一堆并从中取走至少一颗，取走最后一颗球者获胜。两人都采取最优策略，请判断谁必胜。

### 输入格式

第一行一个整数 $T$，表示游戏局数。

每局两行：第一行一个整数 $n$，第二行 $n$ 个整数 $a_1, \dots, a_n$。

### 输出格式

对每局输出一行：小民必胜输出 `Xiaomin`，小欣必胜输出 `Xiaoxin`。

### 样例

```text
输入：
2
3
1 2 3
3
1 2 4

输出：
Xiaoxin
Xiaomin
```

**样例解释：** 第一局 $1 \oplus 2 \oplus 3 = 0$，先手必败，小欣胜；第二局 $1 \oplus 2 \oplus 4 = 7 \ne 0$，先手必胜，小民胜。

### 数据范围

对于 100% 的数据，$1 \le T \le 100$，$1 \le n \le 10^5$，$1 \le a_i \le 10^9$。

**提示：** Nim 定理——先手必胜当且仅当各堆异或和非零。进阶思考：若改为「每次至多取 $k$ 颗」或「取走最后一颗者**输**」（反 Nim），结论如何变化？
