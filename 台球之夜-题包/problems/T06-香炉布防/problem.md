# T06 香炉布防（省选 / NOI−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T6【省选 / NOI−】香炉布防

**算法标签：树形动态规划 / 最小支配集**

### 题目背景

屡焚屡败的小欣终于明白：问题出在「风水」上。台球厅里朋友之间的师徒关系构成一棵树，小欣要在关键人物身边安放香炉，让香气笼罩所有人。

### 题目描述

台球厅里的 $n$ 位朋友构成一棵以 1 号（小民）为根的有根树：除了小民外，每个人都恰好有一位「师傅」（即树上的父亲节点）。

小欣可以在任意一些人身边安放香炉。若某人身边安放了香炉，则**他本人、他的师傅、以及他的所有直接徒弟**都会被香气笼罩。

小欣希望用最少的香炉，让全部 $n$ 个人都被笼罩。请求出最少需要多少个香炉。

### 输入格式

第一行一个整数 $n$。

第二行 $n - 1$ 个整数 $f_2, f_3, \dots, f_n$，其中 $f_i$ 表示 $i$ 号朋友的师傅编号（即树上的父亲）。

### 输出格式

一行一个整数，表示最少的香炉数量。

### 样例

```text
输入：
6
1 1 2 2 3

输出：
2
```

**样例解释：** 树的结构为：1 的徒弟是 $\{2, 3\}$，2 的徒弟是 $\{4, 5\}$，3 的徒弟是 $\{6\}$。在 2 号身边放香炉，笼罩 $\{2, 1, 4, 5\}$；在 3 号身边放香炉，笼罩 $\{3, 1, 6\}$。合计覆盖全部 6 人，且可以证明 1 个香炉无法覆盖所有人。

### 数据范围

- 对于 30% 的数据，$n \le 20$；
- 对于 60% 的数据，$n \le 2000$；
- 对于 100% 的数据，$1 \le n \le 10^5$，$1 \le f_i < i$。

**提示：** 树形 DP，设 $f_{u,0/1/2}$ 分别表示：$u$ 自己放香炉 / $u$ 不放但已被笼罩 / $u$ 不放且暂未笼罩（交给父亲解决）时，$u$ 的子树内的最少香炉数。
