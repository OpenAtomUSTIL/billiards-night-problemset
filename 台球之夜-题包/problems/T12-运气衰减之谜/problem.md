# T12 运气衰减之谜（普及+ / 提高）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T12【普及+ / 提高】运气衰减之谜

**算法标签：树状数组 / 归并排序（逆序对）**

### 题目背景

小欣坚称小民的运气在后半夜「开始衰减」，证据是：很多局的运气值比它前面某些局还低。小民不服，要求精确计算「衰减程度」。

### 题目描述

小民当晚 $n$ 局比赛的运气值依次为 $a_1, a_2, \dots, a_n$。定义「衰减程度」为序列的**逆序对个数**，即满足 $i < j$ 且 $a_i > a_j$ 的有序对 $(i, j)$ 的数量。

### 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, \dots, a_n$。

### 输出格式

一行一个整数，表示逆序对个数。

### 样例

```text
输入：
5
3 1 2 5 4

输出：
3
```

**样例解释：** 逆序对为 $(3,1)$、$(3,2)$、$(5,4)$。

### 数据范围

- 对于 30% 的数据，$n \le 10^3$；
- 对于 100% 的数据，$1 \le n \le 10^5$，$1 \le a_i \le 10^9$（注意离散化）。
