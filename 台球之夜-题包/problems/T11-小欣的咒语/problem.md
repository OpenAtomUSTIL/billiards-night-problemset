# T11 小欣的咒语（普及+ / 提高）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T11【普及+ / 提高】小欣的咒语

**算法标签：字符串匹配（KMP）**

### 题目背景

小欣焚香时念的咒语被小民偷偷录了下来。小民怀疑咒语里反复出现了某个「关键词」，想统计它到底出现了几次——重叠出现也算数。

### 题目描述

给定咒语文本串 $T$ 和关键词 $S$（均由小写英文字母组成），求 $S$ 在 $T$ 中作为子串出现的次数（允许重叠，例如 `aaaa` 中 `aa` 出现 3 次）。

### 输入格式

第一行字符串 $T$。

第二行字符串 $S$。

### 输出格式

一行一个整数，表示出现次数。

### 样例

```text
输入：
aaaa
aa

输出：
3
```

### 数据范围

- 对于 30% 的数据，$|T|, |S| \le 10^3$；
- 对于 100% 的数据，$1 \le |S| \le |T| \le 10^6$。
