# T15 巅峰时刻（提高+ / 省选−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T15【提高+ / 省选−】巅峰时刻

**算法标签：单调队列（滑动窗口最值）**

### 题目背景

小欣复盘小民每一局的得分，想找出「任意连续 $k$ 局内的巅峰单局」——她要据此 pinpoint 小民运气最旺的时间窗口。

### 题目描述

给定长度为 $n$ 的得分序列 $a_1, \dots, a_n$ 和窗口大小 $k$，对每个位置 $i$（$k \le i \le n$），输出区间 $[i - k + 1, i]$ 内的最大值。

### 输入格式

第一行两个整数 $n, k$。

第二行 $n$ 个整数 $a_1, \dots, a_n$。

### 输出格式

一行 $n - k + 1$ 个整数，空格分隔。

### 样例

```text
输入：
8 3
1 3 -1 -3 5 3 6 7

输出：
3 3 5 5 6 7
```

### 数据范围

- 对于 40% 的数据，$n \le 10^3$；
- 对于 100% 的数据，$1 \le k \le n \le 10^6$，$|a_i| \le 10^9$。要求 $O(n)$ 或 $O(n \log n)$。
