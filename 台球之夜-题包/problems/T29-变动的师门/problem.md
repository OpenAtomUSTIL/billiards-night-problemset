# T29 变动的师门（NOI / NOI+ / CTSC）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T29【NOI / NOI+ / CTSC】变动的师门

**算法标签：动态树（Link-Cut Tree）**

### 题目背景

师徒关系并非一成不变——今晚就有人当场拜师、当场决裂。小欣需要实时维护这棵「流动的树」，并随时查询某条师徒链上所有人运气值的异或和。

### 题目描述

初始时有 $n$ 个孤立的节点，第 $i$ 个节点的权值为 $a_i$。支持以下四种操作，共 $m$ 次：

1. `0 x y`：查询节点 $x$ 到节点 $y$ 路径上所有点权的异或和；若 $x$ 与 $y$ 不连通，输出 `-1`；
2. `1 x y`：连接 $x$ 与 $y$（保证连接后仍是一片森林）；
3. `2 x y`：断开 $x$ 与 $y$ 之间的边（保证该边存在）；
4. `3 x y`：将节点 $x$ 的权值改为 $y$。

### 输入格式

第一行两个整数 $n, m$。

第二行 $n$ 个整数 $a_1, \dots, a_n$。

接下来 $m$ 行，每行描述一次操作。

### 输出格式

对每个操作 0，输出一行一个整数。

### 样例

```text
输入：
3 5
1 2 3
1 1 2
1 2 3
0 1 3
2 2 3
0 1 3

输出：
0
-1
```

**样例解释：** 连接 $1-2$、$2-3$ 后，路径 $1 \to 3$ 的异或和为 $1 \oplus 2 \oplus 3 = 0$；断开 $2-3$ 后，1 与 3 不连通，输出 $-1$。

### 数据范围

- 对于 30% 的数据，$n, m \le 10^3$；
- 对于 100% 的数据，$1 \le n, m \le 10^5$，$0 \le a_i, y \le 10^9$。
