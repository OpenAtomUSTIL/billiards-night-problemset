# T25 香味分配（省选 / NOI−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T25【省选 / NOI−】香味分配

**算法标签：网络流（最小费用最大流）**

### 题目背景

小欣的香炉要分配到各张球桌。每位朋友去每张桌子打球的「熏香收益」不同，小欣想让总收益最大……不对，是安排成本最小。

### 题目描述

有 $n$ 位朋友和 $n$ 张球桌，第 $i$ 位朋友去第 $j$ 张球桌会产生成本 $c_{i,j}$。每位朋友恰好分配到一张球桌，每张球桌恰好分配给一位朋友。求总成本的最小值。

### 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行 $n$ 个整数，第 $i$ 行第 $j$ 个数为 $c_{i,j}$。

### 输出格式

一行一个整数，表示最小总成本。

### 样例

```text
输入：
2
1 5
5 2

输出：
3
```

**样例解释：** 朋友 1 去桌 1（成本 1），朋友 2 去桌 2（成本 2），总成本 3。

### 数据范围

- 对于 30% 的数据，$n \le 10$；
- 对于 100% 的数据，$1 \le n \le 100$，$0 \le c_{i,j} \le 10^3$。

**提示：** 建二分图，源点向每位朋友、每张球桌向汇点连容量 1 费用 0 的边，朋友 $i$ 向球桌 $j$ 连容量 1 费用 $c_{i,j}$ 的边，跑最小费用最大流。
