# T26 两难之约（省选 / NOI−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T26【省选 / NOI−】两难之约

**算法标签：2-SAT（强连通分量）**

### 题目背景

散场前朋友们约定下次聚会，但每个人都有两个备选时间段，且朋友之间有 $m$ 条「绑定关系」：「若 $i$ 选了某个时段，则 $j$ 必须选某个时段」。小民需要判断是否存在满足所有绑定关系的安排方案。

### 题目描述

共有 $n$ 位朋友，第 $i$ 位朋友的选择为 $x_i \in \{0, 1\}$（0 表示周六场，1 表示周日场）。共有 $m$ 条约束，每条约束形如 $(i, a, j, b)$，表示「若 $x_i = a$，则必须 $x_j = b$」。

请判断是否存在满足全部约束的方案；若存在，输出任意一组合法解。

### 输入格式

第一行两个整数 $n, m$。

接下来 $m$ 行，每行四个整数 $i, a, j, b$。

### 输出格式

若无解，输出一行 `IMPOSSIBLE`。

若有解，第一行输出 `POSSIBLE`，第二行输出 $n$ 个整数 $x_1, \dots, x_n$（空格分隔），表示一组合法方案。

### 样例

```text
输入：
2 2
1 0 2 1
2 1 1 0

输出：
POSSIBLE
1 0
```

**样例解释：** 两条约束分别为「若 $x_1=0$ 则 $x_2=1$」和「若 $x_2=1$ 则 $x_1=0$」。取 $x_1=1, x_2=0$：两条约束的前件均为假，约束全部成立。（$x_1=0, x_2=1$ 同样合法——本题输出任意合法解均可，正式评测采用 SPJ。）

### 数据范围

- 对于 30% 的数据，$n, m \le 20$；
- 对于 100% 的数据，$1 \le n, m \le 10^6$，$a, b \in \{0, 1\}$。

**提示：** 每个变量拆成两个点，约束转化为蕴含边，Tarjan 缩点后检查 $x_i$ 与 $\neg x_i$ 是否同在一个强连通分量。
