# T20 屠龙之杆（NOI / NOI+ / CTSC）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T20【NOI / NOI+ / CTSC】屠龙之杆

**算法标签：FFT / NTT（多项式乘法）**

### 题目背景

小民最后一杆「屠龙之杆」技惊四座。事后大家争论这一杆和小欣的招牌杆法组合起来会有多少种「总进球数」。两人各自杆法的进球分布已知，答案藏在一个卷积里。

### 题目描述

小民的杆法进球分布为序列 $A = (a_0, a_1, \dots, a_{n})$，其中 $a_i$ 表示一杆进 $i$ 个球的方案数；小欣的为 $B = (b_0, b_1, \dots, b_{m})$。

两人各打一杆，设总进球数为 $s$ 的方案数为 $c_s$。显然

$$c_s = \sum_{i + j = s} a_i b_j$$

即 $C = A * B$（多项式乘法）。请输出 $c_0, c_1, \dots, c_{n+m}$，每个数对 $998244353$ 取模。

### 输入格式

第一行两个整数 $n, m$。

第二行 $n + 1$ 个整数 $a_0, \dots, a_n$。

第三行 $m + 1$ 个整数 $b_0, \dots, b_m$。

### 输出格式

一行 $n + m + 1$ 个整数，空格分隔。

### 样例

```text
输入：
2 1
1 2 1
1 1

输出：
1 3 3 1
```

**样例解释：** $c_0 = 1$，$c_1 = 1 + 2 = 3$，$c_2 = 2 + 1 = 3$，$c_3 = 1$。

### 数据范围

- 对于 30% 的数据，$n, m \le 10^3$；
- 对于 100% 的数据，$0 \le n, m \le 10^5$，$0 \le a_i, b_j < 998244353$。

**提示：** 模数 $998244353 = 119 \times 2^{23} + 1$，原根为 3，适合 NTT。
