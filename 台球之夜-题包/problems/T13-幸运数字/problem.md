# T13 幸运数字（提高+ / 省选−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T13【提高+ / 省选−】幸运数字

**算法标签：字典树（0-1 Trie / 最大异或对）**

### 题目背景

散场前，朋友们玩起了一个游戏：每人报一个幸运数字，若两人数字的异或值很大，就说明「八字相合」。小欣想找出全场最相合的一对。

### 题目描述

给定 $n$ 个非负整数 $a_1, \dots, a_n$，求 $\max\limits_{1 \le i < j \le n} (a_i \oplus a_j)$，其中 $\oplus$ 表示按位异或。

### 输入格式

第一行一个整数 $n$。

第二行 $n$ 个非负整数 $a_1, \dots, a_n$。

### 输出格式

一行一个整数，表示最大异或值。

### 样例

```text
输入：
4
1 2 3 4

输出：
7
```

**样例解释：** $3 \oplus 4 = 7$。

### 数据范围

- 对于 30% 的数据，$n \le 10^3$；
- 对于 100% 的数据，$2 \le n \le 10^5$，$0 \le a_i < 2^{31}$。
