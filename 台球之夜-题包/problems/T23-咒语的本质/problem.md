# T23 咒语的本质（NOI / NOI+ / CTSC）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T23【NOI / NOI+ / CTSC】咒语的本质

**算法标签：后缀自动机（SAM）**

### 题目背景

小欣的咒语冗长而重复。小民嘲讽道：「你这咒语，本质不同的片段能有几个？」小欣不服，要求精确统计。

### 题目描述

给定一个由小写英文字母组成的字符串 $S$，求 $S$ 的**本质不同子串**个数（出现位置不同但内容相同的子串只计一次）。

### 输入格式

一行一个字符串 $S$。

### 输出格式

一行一个整数。

### 样例

```text
输入：
abab

输出：
7
```

**样例解释：** 本质不同子串为 `a`、`b`、`ab`、`ba`、`aba`、`bab`、`abab`，共 7 个。

### 数据范围

- 对于 30% 的数据，$|S| \le 10^3$；
- 对于 100% 的数据，$1 \le |S| \le 10^6$。

**提示：** 后缀自动机中每个状态 $u$ 贡献 $\text{len}(u) - \text{len}(\text{link}(u))$ 个不同子串。
