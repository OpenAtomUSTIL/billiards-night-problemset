# T08 朋友圈（普及−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T8【普及−】朋友圈

**算法标签：并查集**

### 题目背景

台球厅里人来人往，一起打过球的就算「一个圈子的人」。小欣想搞明白：今晚到底哪些人和小民是同一个圈子的。

### 题目描述

今晚共有 $n$ 位朋友（编号 $1 \sim n$）。最初每个人自成一圈。接下来发生了 $m$ 场「同桌打球」，每场给出两个人 $x, y$，表示两人同圈（圈子具有传递性：若 $a$ 与 $b$ 同圈、$b$ 与 $c$ 同圈，则 $a$ 与 $c$ 同圈）。

之后小欣提出 $q$ 次询问，每次给出两个人 $x, y$，请回答他们是否同圈。

### 输入格式

第一行三个整数 $n, m, q$。

接下来 $m$ 行，每行两个整数 $x, y$，表示一场同桌打球。

接下来 $q$ 行，每行两个整数 $x, y$，表示一次询问。

### 输出格式

对每次询问输出一行：同圈输出 `Yes`，否则输出 `No`。

### 样例

```text
输入：
6 3 3
1 2
2 3
4 5
1 3
3 4
4 5

输出：
Yes
No
Yes
```

### 数据范围

对于 100% 的数据，$1 \le n \le 10^5$，$0 \le m, q \le 2 \times 10^5$。
