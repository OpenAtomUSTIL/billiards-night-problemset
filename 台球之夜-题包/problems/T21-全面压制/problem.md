# T21 全面压制（省选 / NOI−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T21【省选 / NOI−】全面压制

**算法标签：CDQ 分治（三维偏序）**

### 题目背景

小欣复盘时发现：评价一局球要看三个维度——准度、力度、运气。若局 $j$ 的三个维度都不超过局 $i$，则称局 $i$ **压制**局 $j$。小欣想知道每一局各压制了多少局，以此论证小民「名不副实」。

### 题目描述

共 $n$ 局比赛，第 $i$ 局有三个属性 $a_i, b_i, c_i$。定义

$$f(i) = \#\{j \ne i \mid a_j \le a_i,\ b_j \le b_i,\ c_j \le c_i\}$$

对每个 $i$ 输出 $f(i)$。

### 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行三个整数 $a_i, b_i, c_i$。

### 输出格式

$n$ 行，第 $i$ 行为 $f(i)$。

### 样例

```text
输入：
3
1 1 1
2 2 2
2 2 3

输出：
0
1
2
```

### 数据范围

- 对于 30% 的数据，$n \le 10^3$；
- 对于 100% 的数据，$1 \le n \le 10^5$，$1 \le a_i, b_i, c_i \le 2 \times 10^5$。

**提示：** 按 $a$ 排序后对 $b$ 做 CDQ 分治，用树状数组维护 $c$；注意处理三个属性完全相同的局。
