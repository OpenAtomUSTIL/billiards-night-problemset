# T30 集齐七色球（省选 / NOI−）

> 系列背景：2026 年 11 月 5 日，小民和小欣饭后前往台球厅，从 23 点切磋到次日 1 点。小欣技术很好，小民运气也不差（50%~300%）。期间来了不少朋友。小欣多次焚香试图打破小民的运气，惨淡收场，最终小民结账 38 元。

## T30【省选 / NOI−】集齐七色球

**算法标签：期望 DP**

### 题目背景

打烊前的最后一项娱乐：摸球。袋子里等概率摸出 $n$ 种颜色球中的一种（摸完放回）。小民扬言自己运气值 300%，能迅速集齐全部颜色。小欣冷笑一声，掏出了期望公式。

### 题目描述

每次摸球等概率得到 $n$ 种颜色中的任意一种（相互独立，摸后放回）。求**集齐全部 $n$ 种颜色所需摸球次数的期望值**。

### 输入格式

第一行一个整数 $n$。

### 输出格式

一行一个实数，表示期望摸球次数，保留两位小数。

### 样例

```text
输入：
2

输出：
3.00
```

**样例解释：** 第一球必得新颜色；之后每次有 $1/2$ 概率摸到另一种颜色，期望再摸 $2$ 次。总计 $1 + 2 = 3$。

### 数据范围

对于 100% 的数据，$1 \le n \le 10^4$。

**提示：** 设 $E_i$ 为已集齐 $i$ 种颜色时还需摸球次数的期望，则 $E_n = 0$，且 $E_i = \frac{i}{n} E_i + \frac{n-i}{n} E_{i+1} + 1$，整理得 $E_i = \frac{n}{n - i} + E_{i+1}$。
