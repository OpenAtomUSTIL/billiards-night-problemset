# 台球之夜

> 2026 年 11 月 5 日深夜，小民和小欣在台球厅从 23 点切磋到次日 1 点。
> 小欣技术很好，小民运气也不差（运气值 50% ~ 300%）。小欣多次焚香试图压制小民的运气，最终以失败告终。
> 这 33 道题，记录的就是那个晚上的故事。

一套**故事线贯穿的算法题集**：33 道题按同一晚的时间线展开，难度从「入门」一路爬到「NOI+/CTSC」，每题均含完整题面、C++17 标程和约 10 组测试数据（共约 235 MB），可直接用于评测或训练。

## 仓库结构

```
├── 台球之夜-洛谷风格题集.md     # 完整题集（33 题题面合集）
└── 台球之夜-题包/
    ├── problems/
    │   └── T01-小民买单/
    │       ├── problem.md       # 单题题面（背景/描述/输入输出/样例/数据范围/提示）
    │       ├── std.cpp          # C++17 标程（带注释）
    │       └── data/            # 约 10 组测试点：1 为样例，2~3 小，4~6 中，7~10 大
    ├── solutions/               # 33 份标程汇总（T01.cpp ~ T33.cpp）
    └── tools/
        └── build_package.py     # 题包构建器：拆分题面、生成数据、暴力对拍
```

## 快速上手

编译并对拍某一道题：

```bash
g++ -O2 -std=c++17 -o std "台球之夜-题包/problems/T01-小民买单/std.cpp"
./std < "台球之夜-题包/problems/T01-小民买单/data/1.in" > out.txt
diff out.txt "台球之夜-题包/problems/T01-小民买单/data/1.out"
```

重建全部测试数据（支持断点续跑）：

```bash
cd 台球之夜-题包/tools && python build_package.py
```

## 评测注意事项

- 每题第 1 组数据为题面样例，答案经手工验算；小规模点均通过**独立暴力实现**对拍校验。
- **T26（两难之约）为 SPJ 题**：`.out` 仅给出一组合法解，评测时需校验合法性，不能逐字节比对。
- T27 中询问 `k=0` 时答案为 `NAY`（题目要求两个**不同**节点）。
- T07 大数据点采用「奇偶构造」，保证球永不进袋。
- T18 数据最大 `n=14`（Python 参考实现的性能上限；标程可过 `n=16`）。
